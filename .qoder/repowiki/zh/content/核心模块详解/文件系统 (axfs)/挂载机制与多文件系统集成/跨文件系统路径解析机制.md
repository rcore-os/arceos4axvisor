```mermaid

根目录->>API : 返回VfsNodeRef
API->>应用 : 返回结果
Note over 根目录,文件系统 : 最长前缀匹配算法确保<br/>正确选择挂载的文件系统
```

### 符号链接与权限检查
系统在路径解析过程中集成权限检查和符号链接处理机制。对于符号链接，系统会递归解析其指向的目标路径；对于权限检查，则验证用户对目标资源的访问权限。

```mermaid
flowchart TD
Start([开始路径解析]) --> Normalize["规范化路径"]
Normalize --> CheckAbsolute{"绝对路径?"}
CheckAbsolute --> |是| UseRoot["使用根目录作为起点"]
CheckAbsolute --> |否| UseCurrent["使用当前目录作为起点"]
UseRoot --> FindMount["查找匹配的挂载点"]
UseCurrent --> FindMount
FindMount --> HasMatch{"找到匹配?"}
HasMatch --> |是| Delegate["委派给对应文件系统"]
HasMatch --> |否| UseMain["使用主文件系统"]
Delegate --> CheckSymlink{"符号链接?"}
UseMain --> CheckSymlink
CheckSymlink --> |是| ResolveLink["解析符号链接目标"]
CheckSymlink --> |否| CheckPermission["检查访问权限"]
ResolveLink --> Normalize
CheckPermission --> IsValid{"权限有效?"}
IsValid --> |是| ReturnSuccess["返回目标节点"]
IsValid --> |否| ReturnError["返回权限拒绝"]
ReturnSuccess --> End([结束])
ReturnError --> End
```

## 性能考虑
路径解析的性能关键在于挂载点查找效率。当前实现采用线性搜索算法，时间复杂度为O(n)，其中n为挂载点数量。对于大量挂载点的场景，建议优化为基于trie树的数据结构以提高查找效率。

## 故障排除指南
常见问题包括挂载点冲突、路径不存在和权限不足等。调试时应首先检查挂载点配置，然后验证路径格式，最后确认用户权限设置。

axfs通过精心设计的根目录管理和挂载点机制，实现了高效的跨文件系统路径解析。系统采用最长前缀匹配算法确保正确选择目标文件系统，并集成权限检查和符号链接处理功能，提供了完整的文件系统服务。
